# 高強度間歇訓練計時器

**1.0**

手機優先的間歇訓練計時器，介面為繁體中文。準備、鍛鍊、休息、循環休息與冷卻都會用語音和嗶聲提示；較長的階段在最後三秒說「三、二、一」，接著說出下一個動作。

線上版本：<https://eb-barry.github.io/HIT-timer/>

## 1.0 包含

- 一條課表從準備走到完成：鍛鍊、休息、循環休息、冷卻。長度為 0 的階段會跳過。
- 預設計時器「高強度間歇訓練」，以及 Tabata。可以新增、重新命名、刪除自己的計時器。
- 倒數環、總時間，以及週期、循環兩張珠狀進度卡。標題是總數（例如「10 個週期」），環心是正在進行的數字。格子從 12 點順時針亮起，完成的格子保持亮著。
- 開始、暫停、跳過、重新開始。暫停不會重播階段名稱；跳過只報新的階段。
- 語音、嗶聲、震動、螢幕常亮，以及各自的音量。第一次開始會提醒確認手機音量。
- 設定存在這台裝置上。回到主畫面時，名稱和課表內容與設定頁選定的計時器一致。
- 可安裝到主畫面。真人 MP3 可以逐句取代電腦語音。

## 怎麼用

主畫面中間是目前階段和倒數。下方兩張卡片的外緣與倒數環對齊。

| 位置 | 作用 |
| --- | --- |
| 右上齒輪 | 開啟設定 |
| 左下 | 重新開始。進行中會先確認 |
| 中間 | 開始、暫停、繼續。完成後是再練一次 |
| 右下 | 跳過這個階段 |

週期環是深青綠，正在進行的那格發亮。循環進行時，那一格內層是白色、外圈是淺黃光暈；準備開始時外圈是淺綠光暈。該循環結束後才塗上淺棕。訓練全部完成後，數字停在最後一輪，兩圈都保持亮起。

每個循環的最後一輪會改接循環休息；最後一個循環的最後一輪則進入冷卻，然後完成。準備階段每一秒一聲嗶聲，其他階段安靜到最後三秒。階段本身只有 3 秒或更短時，只說出動作名稱。

## 預設課表

| | 高強度間歇訓練 | Tabata |
| --- | --- | --- |
| 準備 | 5 秒 | 5 秒 |
| 鍛鍊 | 30 秒 | 20 秒 |
| 休息 | 10 秒 | 10 秒 |
| 週期 | 10 | 8 |
| 循環 | 3 | 1 |
| 循環休息 | 30 秒 | 無 |
| 冷卻 | 30 秒 | 無 |
| 總時間 | 21:05 | 03:55 |

在設定裡調整秒數、週期或循環後要按「儲存」。尚未儲存就返回或切換計時器時，可以選擇儲存或放棄。語音、嗶聲、震動和螢幕常亮會立刻生效。

## 開發

```bash
npm install
npm run dev
npm test
```

`npm run build` 會先做型別檢查再產出 `dist`。

## GitHub Pages

`https://eb-barry.github.io/HIT-timer/` 必須發布建置後的 `dist`，不能直接打開倉庫裡的 `index.html`。推上 `main` 後，GitHub Actions 會以 `/HIT-timer/` 為基底路徑建置並部署。倉庫的 Pages 設定要選 **GitHub Actions**，不要選 Deploy from a branch。

## 真人語音

電腦語音是暫時的做法。把 MP3 放到 `public/voices/`，檔名固定如下：

| 句子 | 檔名 |
| --- | --- |
| 準備 | `prepare.mp3` |
| 鍛鍊 | `work.mp3` |
| 休息 | `rest.mp3` |
| 循環休息 | `cycle-rest.mp3` |
| 冷卻 | `cooldown.mp3` |
| 完成 | `complete.mp3` |
| 三 | `three.mp3` |
| 二 | `two.mp3` |
| 一 | `one.mp3` |

可以只放其中幾句。三、二、一請各錄成短於一秒的獨立檔案。放好之後，在右上角齒輪的「設定」裡按「重新偵測語音檔」，或把對應的 id 寫進 `public/voices/index.json` 的 `clips`。缺檔的句子會繼續用電腦語音。
